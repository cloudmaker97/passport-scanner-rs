# Settings

Click **Einstellungen** (*settings*) to open them.

## Sprache · Language

Choose **Deutsch** or **English**. All buttons and messages change at once.
Until you choose, the program follows the language of Windows (German for a
German Windows, English for an English one, German otherwise). The program
remembers your choice. This guide uses the German labels; in English the
settings button is called **Settings**.

## Darstellung (appearance)

Choose **Dunkel** (*dark*) or **Hell** (*light*). The program remembers your
choice.

## Automatisch scannen (scan automatically)

Starts a scan as soon as a document is put on the glass. See chapter
[Scanning a Document](#scanning-a-document).

## Aufnahmeprofil (capture profile)

| Profile | Use it for |
|---|---|
| **Allgemein** (*general*) | All documents. This is the default. |
| **Ausweis** (*ID card*) | ID cards, with the scanner's special ID light. |
| **Ausweis · heller** (*ID card, brighter*) | Like *Ausweis*, but brighter. Use it if ID pictures look too dark. |

The program remembers your choice. The ID profiles need the factory ID
calibration; without it the program refuses the switch and tells you why.

## Signalton (beep)

Beeps when a scan is finished.

## Kalibrierung (calibration)

See chapter [Calibration](#calibration).

## PDF-Speicherort (PDF location)

Shown as **Bei jedem Export fragen** (*ask on every export*) until you set a
folder. Click **Ordner wählen …** (*choose folder*) to pick one: from then on
**PDF** saves there without asking. **Zurücksetzen** (*reset*) goes back to
asking. The program remembers the folder. In the browser this setting does not
exist; PDFs go to the browser's download folder.
