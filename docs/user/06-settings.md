# Settings

Click **Settings** to open them.

## Language

Choose **English** or German (listed under its own name). All buttons and messages change at once.
Until you choose, the program follows the language of Windows (German for a
German Windows, English for an English one, German otherwise). The program
remembers your choice. This guide uses the English labels.

## Appearance

Choose **Dark** or **Light**. The program remembers your
choice.

## Scan automatically

Starts a scan as soon as a document is put on the glass. See chapter
[Scanning a Document](#scanning-a-document).

## Beep

Beeps when a scan is finished.

## Calibration

See chapter [Calibration](#calibration).

## PDF location

Shown as **Ask on every export** until you set a folder. Click
**Choose folder …** to pick one: from then on
**PDF** saves there without asking. **Reset** goes back to
asking. The program remembers the folder. In the browser this setting does not
exist; PDFs go to the browser's download folder.

## Web interface and MCP

See chapter [Browser and Other Programs](#browser-and-other-programs).

## Updates

The program shows its version here. Each time it starts, it asks the project's
releases page on the internet whether there is a newer version. Nothing else is
sent.

When there is one, **Update available** appears with the new version number,
here and in the top bar. Click **Install update**: the program downloads the
new version, checks that it arrived intact and puts it in place of the old
files in its folder. Your settings, calibration and saved PDFs are not touched.
Then click **Restart**; the program closes and opens again in the new version.
Finish your current document first: the restart ends the scanning session.

**Check for updates** asks again by hand. Without an internet connection the
check fails quietly and the program works as before. If the program folder
cannot be written to, the installation says so; move the folder somewhere you
may write to, or download the new version by hand as in chapter
[Installation](#installation).
