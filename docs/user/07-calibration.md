# Calibration

The scanner lamp does not light the glass evenly. Calibration measures this
once, so every picture can be corrected and looks evenly bright.

## Do I need to do anything?

Usually not. If the factory calibration is on the PC, the program uses it and
shows **Werkskalibrierung** (*factory calibration*).

If the status shows **Kalibrierung fehlt** (*calibration missing*), or if your
pictures are clearly darker on one side, measure your own.

## Measure your own calibration

1. Open **Einstellungen** → **Kalibrierung**.
2. Make sure the profile is **Allgemein**. Own measurement only works there.
3. Put a clean, blank sheet of white paper on the glass. Nothing printed on it.
4. Click **Messen** (*measure*).

If the sheet is not blank, the program refuses and tells you why. Never use a
card or a printed page for calibration.

Your own measurement never overwrites the factory files.

## Go back to the factory calibration

Click **Eigene entfernen** (*remove own*). The program uses the factory
calibration again.
