# Application icon

`icon.svg` in the repository root is the application icon, made for Passport
Scanner and distributed under the project's MIT License. `icon-tile.svg` sets
it on a dark rounded tile; `icon.png` (512 × 512) is rendered from the tile and
embedded in the desktop window and as the web favicon, and
`crates/passport-scanner-desktop/assets/icon.ico` holds the 16 to 256 pixel
sizes for the Windows executable. The user guide draws the SVG directly.
