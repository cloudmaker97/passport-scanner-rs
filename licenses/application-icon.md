# Application icon

The supplied `icon.png` is embedded unchanged in the Iced desktop application and the web favicon. `crates/passport-scanner-desktop/assets/icon.ico` resamples that PNG to 16, 24, 32, 48, 64, 128, and 256 pixel sizes for the Windows executable. The design and transparency are preserved; no replacement artwork was generated.

The supplier referenced Google's Material Design Icons project:
https://github.com/google/material-design-icons

The complete upstream Apache License 2.0 is included in
`material-design-icons-LICENSE.txt`, copied from:
https://raw.githubusercontent.com/google/material-design-icons/master/LICENSE

The exact upstream asset and revision of the supplied PNG were not recorded.
